# 手机端 App（原生安卓）

和电脑上的 Communication 工具配对，**能选整个文件夹**并双向同步。
网页版做不到这一点（安卓的 `webkitdirectory` 会被系统选择器降级成"选文件"），
原生 App 用安卓的 SAF（`ACTION_OPEN_DOCUMENT_TREE`）拿持久读写权限，所以目录是真的可以选、可以写的。

## 安装

```bat
:: 手机用数据线连电脑、开启 USB 调试后：
adb install -r out\commsync-mobile.apk
```

或者把 `out\commsync-mobile.apk` 拷到手机上直接点开安装（首次需要允许"安装未知来源应用"）。
要求 Android 8.0（API 26）以上；这个包是 debug 签名的，自用足够，不需要上架。

## 用法

1. **电脑上**先启动桌面工具（`启动.bat`），记下界面里的地址（`http://192.168.x.x:47800`）和 6 位配对码。
2. **手机上**打开 App，地址**只填 `IP:端口`** 就行（`192.168.1.6:47800`），`http://` 会自动补上；端口不填默认 47800。
   填 6 位配对码 → 「连接并配对」。点下去会立刻显示「正在连接 …」，3 秒内连不上会直接告诉你原因。
3. 「选择手机上的文件夹」→ 系统会弹出**目录选择器**，选一个文件夹（授权会永久保存，重启手机也不丢）。
4. 在「对方共享的文件夹」里选电脑上那个要同步的目录。
5. 「对比」只做检查；冲突项会出现四个按钮：**保留本地 / 保留远端 / 两个都留 / 跳过**。
6. 「执行同步」提交改动，或者直接点「一键同步」（对比+执行一步完成，遇到冲突会停下来让你选）。
7. **只想拿电脑上一个文件**：用「远端文件（下载）」卡片——列出电脑上的文件，点「下载」→ 选保存位置 → 直接存到手机。
   只下载，**不写进手机上的同步文件夹、不进基线**，对比结果不受影响；对比结果里每个"远端有"的文件也有单独的下载按钮。
   下载会边写边算 SHA-256，与远端不一致会提示并删掉半成品。

删除操作默认关闭（和电脑端一致）：勾上「允许同步删除操作」才会真的删。

## 连不上怎么查

**先点「测试连接」**：它不需要配对码，只做 3 秒 TCP 探测 + 一次问候接口，能立刻告诉你三种情况里的哪一种——

- 状态区显示「地址可用：电脑名（v1.1.0，共享 N 个文件夹）」→ 网络和地址都没问题，问题只可能在配对码；
- 显示「连不上 x.x.x.x:47800（ConnectException）」→ 网络/防火墙/地址问题，往下看；
- 显示「这个地址不是本工具的节点」→ 端口填错了（或填成了别的服务）。

其它排查点：

1. **用手机浏览器再验一次**：打开 `http://电脑IP:47800/api/ping`，能看到 `{"ok":true,...}` 说明网络通。
2. **确认是同一个 WiFi**：手机走 4G、电脑在另一个网段都连不上；路由器的"AP 隔离"也会拦。
3. **电脑防火墙**：首次启动若弹过提示要允许"专用网络"；没有就手动给 TCP 47800 放行。
4. **地址填对**：是电脑的局域网 IP（电脑界面上「局域网」那一行），不是 `127.0.0.1`（那是电脑自己）。
5. **配对码太多次会临时封**：连续输错 8 次，服务端会在 1 分钟内拒绝配对（提示"尝试过于频繁"），等一分钟再试。
6. **点按钮没反应**：现在不会了——按钮在处理中会变灰并提示"上一个操作还在进行"，配对过程状态区会实时显示进展；
   以前版本确实存在"上一次请求卡住 → 后续点击被静默丢掉"的问题，重启 App 才能恢复，这一版已修。
7. 想看具体报错：

   ```bat
   adb logcat -d | findstr /i commsync
   ```

### 电脑端「对比」报"无法连接对端"，而手机端点对比正常

这是 v1 手机端服务的一个 bug：`/api/peer/manifest` 分支把请求体**读了两次**（先 drain 再按 Content-Length 读），
第二次永远等不到数据，手机端 30 秒 socket 超时后把连接关掉，电脑端就报"无法连接对端"。
对比恰好要用 manifest，所以只有"电脑发起"会失败、手机发起（走的是另一条路径）完全正常。

已在 v1.1 修复：请求体在路由前**只读一次**（`HttpBody`），并加了单测守住"精确读取、不多读"。
升级 APK 后不用重新配对（端口和令牌都没变），重启 App 即可。


## 同步方向（两边都能发起）

手机 App 现在**既是客户端也是服务端**：它会在手机上开一个小 HTTP 服务（默认端口 **47820**），
把选中的 SAF 目录按同一套协议暴露出去。所以：

| 谁发起 | 怎么操作 | 说明 |
| --- | --- | --- |
| 手机 | App 里选「对方共享的文件夹」= 电脑的目录 → 对比 / 一键同步 | 手机主动推或拉 |
| **电脑** | 电脑端「对端设备」里能看到手机的目录 → 在「同步项」里选它 → 对比 / 一键同步 | 电脑主动拉手机的文件 |

两边都能看到对方的文件夹，用的是同一套协议、同一套冲突规则。

**必须重新配对一次**：老版本配对时手机没有交出"给电脑的访问令牌"，电脑因此读不到手机。
装上新版后，在手机上重新点一次「连接并配对」即可，之后电脑端就能列手机的目录了。

两点限制：

- 手机端服务**只在 App 前台时运行**（Android 后台限制）。锁屏久了可能被冻结，此时电脑端扫描会超时——
  把 App 切回前台再试即可。
- 手机上如果既没选目录、服务也没起来，App 会如实告诉电脑"我是纯客户端"，不会给电脑一个连不上的地址。



| | 原生 App | 网页版 `/lite` |
| --- | --- | --- |
| 选整个文件夹 | ✅ 系统目录选择器 | ❌ 安卓会退化成选文件 |
| 双向同步（写回手机磁盘） | ✅ | ❌ 只能下载到"下载目录" |
| 冲突逐条选择 | ✅ | 只能"跳过 / 覆盖" |
| 需要安装 | 要装 APK | 什么都不用装 |
| 自动同步 | ❌ 暂未实现 | ❌ |

## 已知限制

- **没有定时自动同步**：需要在 App 里手动点。要做的话得配前台服务（`ForegroundService` + 通知），下一版再说。
- **一个同步项**：当前是本机一个目录 ↔ 对方一个目录。要同时同步多个目录，先在电脑端切换对方文件夹再对比（基线按"目录+对端+对方目录"分开记，不会串味）。
- **SAF 不能设置文件修改时间**：从电脑拉下来的文件，手机上的 mtime 是"现在的"。因此基线里分别记录两端签名（`localSig` / `remoteSig`），不会因此误报冲突；但"按修改时间判断谁更新"的自动策略在手机端暂未启用。
- 只同步文件，不保留空目录；跳过符号链接。
- 不跑到后台：退到后台时正在传输会继续，但系统回收进程就会中断（下次对比会重新算，不会留下半截文件——写入是先落盘再校验的）。

## 自己构建

环境（这台机器上已就绪）：

| 依赖 | 位置 |
| --- | --- |
| JDK 17 | `C:\Program Files\Java\jdk-17` |
| Android SDK | `%LOCALAPPDATA%\Android\Sdk`（platform-tools + android-35 + build-tools 35.0.0） |
| Gradle 8.9 | `tools\gradle-8.9`（用 `tools\fetch-gradle.ps1` 从腾讯镜像拉，因为这台机器连不上 github.com） |

```bat
:: 重新出包（产物在 out\commsync-mobile.apk）
build-apk.bat

:: 只跑逻辑单测（差异引擎 18 个 + 地址补全 8 个，JVM 上跑，不需要手机）
tools\gradle-8.9\bin\gradle.bat testDebugUnitTest
```

首次安装 SDK（换一台新机器时）：

```powershell
powershell -ExecutionPolicy Bypass -File tools\install-sdk.ps1
```

> 注意：Windows PowerShell 5.1 读没有 BOM 的 `.ps1` 会按 ANSI 解码，中文会变乱码甚至语法报错。
> 这里的脚本要么是纯 ASCII，要么带 UTF-8 BOM，别用编辑器去掉 BOM。

## 代码结构

```
app/src/main/java/com/commsync/mobile/
  Diff.kt          差异引擎（与桌面版 shared/diff.js 同一套规则）
  SyncEngine.kt    扫描编排 + 执行（上传/下载/删除/副本），逐项回写基线
  RemoteClient.kt  对端 HTTP 客户端（配对/清单/哈希/上传/下载/删除/复制 + 连通性探测）
  LocalTree.kt     SAF 目录遍历与读写（这就是"能选文件夹"的关键）
  PeerServer.kt    手机端对端服务：把 SAF 目录按同一套协议暴露给电脑（端口 47820）
  Store.kt         设置与基线持久化
  Format.kt        大小/时间格式化 + 地址补全（只填 IP:端口）
  MainActivity.kt  界面（纯框架控件，不依赖 AndroidX）
app/src/test/java/com/commsync/mobile/
  DiffTest.kt      18 个逻辑用例
  FormatTest.kt    8 个地址补全用例
```

局域网同步（Windows 便携版）
==============================

这是免安装版本：整个文件夹拷到哪儿都能用，不需要电脑上装 Node。

怎么用
------
1. 双击 Communication.exe
2. 窗口里会显示「服务运行中」和一个地址（一般是 http://127.0.0.1:47800）
3. 点「打开界面」开始用（也可以手动在浏览器里打开这个地址）
4. 用完点「停止并退出」，或者直接关窗口 —— 后台服务会一起关掉

数据在哪
--------
- data\          本机身份、配对码、共享文件夹、已配对的对端、同步基线
- 换台电脑用：把整个文件夹拷过去即可；想保留配对关系，连 data\ 一起拷

注意
----
- 局域网内另一台电脑要连你，需要在 Windows 防火墙弹提示时允许「专用网络」
- 只面向可信局域网：令牌是明文 HTTP 传输，别把端口暴露到公网
- 同一个文件夹只跑一个实例：重复双击不会起第二个服务，会直接指向已在运行的那个

文件说明
--------
Communication.exe   启动器（就是这个）
node.exe            内置的 Node 运行时
app\                程序本体（服务端 + 网页界面）
data\               你的数据（首次运行自动创建）
